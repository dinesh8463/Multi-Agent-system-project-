# AI3403 group project report

Open [the compiled report](AI3403_Project_Report.pdf) or edit `main.tex` and the chapter files. The source uses the 20 original PNGs in `../results/figures/`. Keep the repository layout when compiling.

```sh
cd report
tectonic main.tex
```

With TeX Live, run `latexmk -pdf main.tex` from the same directory. The course-report structure follows the supplied IIT Hyderabad template with a standard LaTeX class.
